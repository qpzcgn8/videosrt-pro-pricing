## 买之前要知道的几个限制

仅支持 Windows。这是最容易踩空的一条，Mac 用户翻到这里就可以关页面了。

一个授权只能激活 1 台设备。换电脑时要在原设备上退出账号，才能在新设备上激活。如果你习惯台式机和笔记本轮流用，需要提前想好主设备是哪台。

虚拟商品交付后不支持退款。授权码发到账号、短信或邮箱之后，就没有反悔的余地。试用版存在的意义就在这里。

赠送的点数会用完。用完之后有两条路：软件内付费充值，或者自己配置阿里云、腾讯云的接口，按各家云服务的标准计费。后一条路成本更可控，但要申请账号、配置 AccessKey，对不熟悉云服务的人有一段学习成本。

识别准确率不是百分之百。标准普通话和英语的表现最好，方言、口音重、专业术语密集的素材仍然会出错，生成字幕后需要人工过一遍。所有语音识别工具都是这个水平，不是这一款的问题。素材里背景音乐或噪音大时，先用人声分离把音轨拆开再识别，准确率会好一些。

授权是按时长算的，不是买断。1 年版到期之后要继续用，得再买一次。购买页面上不会写“永久”，这一点要提前有预期。

能找到的独立第三方评测不多，公开信息主要来自开发者的使用文档和销售页说明。这不算缺点，但意味着你很难从别人的实测里判断它对你的素材效果如何，试用版的权重就更高了。
